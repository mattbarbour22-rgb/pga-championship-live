U.S. OPEN PICK 3 LIVE - CLEAN PRODUCTION VERSION

WHAT THIS VERSION CHANGES
- Public page is read-only: users can refresh without writing to Supabase.
- Round movement arrows are saved from an admin-only URL.
- Arrows compare against the previous completed-round snapshot.
- Eliminated rows show reasons like:
  COVERED BY
  SHAW
  or ALL MC.
- Tee times display as local tournament time plus NZ time.
- U.S. Open config is centralized so you can trial another tournament easily.

MAIN FILES TO EDIT
1) app/lib/tournament.js
   Change tournament title, venue, dates, timezone, image, prize pool, and poolEntries.

2) Vercel Environment Variables
   For U.S. Open:
   SLASH_GOLF_TOURN_ID=026
   SLASH_GOLF_YEAR=2026
   TOURNAMENT_STATE_ID=2026-us-open
   ADMIN_SECRET=choose-a-private-secret

3) Supabase table: public.tournament_state
   Needs columns:
   id text primary key
   tournament_name text
   previous_ranks jsonb
   current_ranks jsonb
   locked_eliminated jsonb
   cut_locked boolean
   leaderboard_updated_at text
   updated_at timestamptz

ADMIN SNAPSHOT URL
After a round is fully complete, open this in your browser:

https://YOUR-SITE.vercel.app/api/admin/save-round-snapshot?secret=YOUR_ADMIN_SECRET

It will only save when every player is F, F*, or MC.
Public users cannot trigger this unless they know your ADMIN_SECRET.

HOW TO TRIAL ANOTHER TOURNAMENT
- Change app/lib/tournament.js display details and timezone.
- Change Vercel env vars:
  SLASH_GOLF_TOURN_ID
  SLASH_GOLF_YEAR
  TOURNAMENT_STATE_ID
- Create or reuse a Supabase row matching TOURNAMENT_STATE_ID.
- Replace poolEntries when you have the spreadsheet.

IMPORTANT
Do not put Supabase POST/write logic back into app/page.js.
That was the cause of public-user write risk and possible timeouts.
